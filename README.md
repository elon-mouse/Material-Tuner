# 🎵 Material Tuner

Material Tuner is a modern Android tuning app Material You design.  
It focuses on clean UI, accurate pitch detection, and smooth needle response.

---

## ✨ Features

- 🎨 Material You dynamic theming
- 🎤 Real-time microphone input
- 📈 Pitch detection engine
- 🎯 Stable monophonic tuning logic
- 🪄 Autocorrelation-based frequency detection
- 🧮 Hanning windowing for spectral accuracy
- 📉 Output smoothing to reduce UI jitter
- 📱 Built using modern Android architecture

---

## 🧠 Pitch Detection Engine

Material Tuner uses:

- Windowing (Hanning/Hamming) to reduce spectral leakage
- Autocorrelation for stable monophonic frequency detection
- Moving average smoothing to prevent needle jitter

---

## 🏗 Tech Stack

- **Kotlin**
- **Coroutines & Flow**
- **AudioRecord API**
- **Material 3**
- **Jetpack Compose (UI)**
- Android Studio
